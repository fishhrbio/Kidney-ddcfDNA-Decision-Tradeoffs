01 / The question

Two measurements.
One biological signal.
Different decisions.

A blood test can describe donor-derived DNA as a fraction or a concentration. What changes when we require both to agree—and how certain are those classifications?

The clinical motivation

A more selective test changes which errors we make.

Kidney-transplant injury releases donor-derived cell-free DNA (dd-cfDNA) into the blood. Fraction expresses donor DNA relative to total cfDNA; concentration describes the amount per volume. Requiring both measurements to be positive can reduce false positives while missing additional rejection cases.

In the source study, absolute concentration was calculated from donor fraction and total cfDNA. That relationship also matters when exploring uncertainty: error in fraction affects calculated concentration.

The result to carry with you

In the published cohort, requiring both measurements to be positive avoided 2 false positives but missed 3 additional rejections compared with fraction alone. The uncertainty extension asks when such classifications remain stable—not whether those hypothetical scenarios improve patient outcomes.

What this project accomplishes

It turns diagnostic percentages into understandable counts, preserves measurement relationships when testing uncertainty, and defines a reproducible route toward molecular interpretation. Published results, synthetic scenarios and proposed analyses are labeled throughout.
